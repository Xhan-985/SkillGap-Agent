## 1. 目标与反目标

**目标**：全站视觉翻新为瑞士网格风——白底黑线 + 国际橙单一强调色 + 超粗字重 + 直角（微圆角 2px）+ 零阴影零渐变；层级靠排印与网格，不靠装饰。

**反目标（反 AI 味清单）**：无紫色/蓝紫渐变、无毛玻璃、无大圆角阴影卡、无 emoji 图标、无装饰性位移动画、无 Inter+Tailwind 模板脸。瑞士风本身即对 AI 模板审美的反驳。

**不做（out of scope）**：暗色模式、信息架构调整、新功能、组件库化、外部字体引入。

## 2. 设计令牌（style.css 以 CSS 自定义属性重写）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ink` | `#111` | 正文、结构线、超粗标题 |
| `--accent` | `#FF4F00` | 强调色（激活态、关键数字、主 CTA、雷达画像层） |
| `--line` | `#111`，1.5-2px | 面板/结构边框 |
| `--hairline` | `#ddd`，1px | 行内分隔 |
| `--paper` | `#fff` | 页面背景 |
| `--radius` | `2px` | 全局唯一圆角值（用户修订：微圆角） |
| 字重 | 800 页面标题 / 700 面板头 / 600 强调 / 400 正文 | 层级全靠字重 |
| 数字 | `font-variant-numeric: tabular-nums` | 所有数值列 |
| 字体栈 | `system-ui, "Segoe UI", "Microsoft YaHei", sans-serif` | 不引外部字体（C2） |

**置信度三档改造**：现绿/黄/红背景色块 → 移除背景色；conf 数字右对齐等宽展示；低置信度（<0.4）行加橙色左侧 2px 边线。语义保留、色块噪音去除。

## 3. 组件规范

1. **顶栏**：白底 + 2px 黑下边线；品牌 `SkillGap·Agent`（中点橙色，字重 800）；导航中文小字距加宽（letter-spacing .05em），激活项 = 黑底白字方块（反色）；China/Global = 分段控件（1.5px 黑边直角组，激活段橙底白字）。
2. **页面头模式**：每页统一——超大标题（26px/800）+ 右侧 meta（窗口/N=，等宽数字）+ 底部 2px 黑线。
3. **编号面板**（总览六视图）：`01`~`06` 橙色两位等宽编号 + 中文标题（700）+ 小型大写英文标签；面板 1.5px 黑边、2px 圆角、无阴影。
4. **技能行**：1px 上细分线表格行；星级 `★☆` → `●●●○○`（实心=墨色填充，空心=1px 描边圈）；技能名 600；conf 等宽右对齐。
5. **市场条形**：1px 黑描边方轨（2px 圆角）+ 橙色填充 + 右列等宽数值；样本不足灰态 = 1.5px 黑虚线框 + `N=0` 标签 + 灰字（保留 D5 诚实灰态语义）。
6. **雷达图**（手写 SVG 保留）：环线墨色；画像层 = 橙色填充（fill-opacity .18）+ 橙描边；类目要求层 = 黑虚线描边无填充；标签 400。
7. **按钮**：主 CTA（生成推荐/提交类）= 橙底白字；次级 = 黑底白字；危险操作 = 白底 1.5px 黑边红字（`button.danger`）；hover 仅换色/边线加粗（1.5px→2px），无位移无阴影。
8. **表格**（ROI/质量页）：小型大写表头（600，letter-spacing .08em）+ 1px 细分行线 + 数值列等宽右对齐。
9. **表单**：1.5px 黑边 2px 圆角输入框；focus = 2px 橙边 + 无 outline 光晕；textarea/select 同。
10. **优先级徽章**（P0/P1）：黑底白字 / 橙底白字小方块。
11. **空态**：`——` 橙色双破折号 + 灰字说明。
12. **页脚**：1px 上细线 + 小号灰字 meta（居中保留）。

## 5. 实现路径（低风险）

- `style.css` 全量重写：令牌层（:root 变量）+ 基础层 + 组件层，约 300-400 行。
- `base.html`：顶栏/页脚结构小改（分段控件、品牌中点）。
- 七页模板：**只调 class 与局部结构**（页面头模式、编号面板包裹）；DOM 语义与数据绑定不动。
- `app.js`：不动（若有 class 引用随模板同步核对）。
- 测试风险：API 测试断言文本/结构不断言样式；模板测试核对文本——预期零改动；全量回归 540。
- UI_SPEC §3 更新：设计语言描述（瑞士网格风、微圆角 2px、无动画保持——仅 hover 换色）。
