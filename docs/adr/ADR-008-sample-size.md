# ADR-008：为什么市场统计必须显示 Sample Size？

状态：**已接受（Phase 1 冻结，数据诚实红线）** ｜ 日期：2026-08-31

## Context

需求第九节：系统绝不能在只有 30 条样本时告诉用户"中国 AI 岗位中 Python 占 82%"。Phase 0 市场研究发现：公开渠道不存在可复现的中文技能频率统计（唯一小样本是 23 条 JD 的非官方统计，只能作假设生成）；培训机构口径数据（500% 增长等）被明确排除。本项目数据规模天花板是数百条级（ADR-001 合规代价）——**统计诚实性是产品可信度的生命线**。

## Options

| 选项 | Pros | Cons |
|---|---|---|
| **样本量守门 + 分级置信度** | 小样本也能给出诚实的相对结论（标注 Low confidence）；用户可自行判断可信度；趋势功能不会伪造 | 统计覆盖率受限（切片过细即不出数） |
| 只展示百分比（N 隐藏） | 界面干净 | 30 条样本冒充市场真相——数据造假，产品根基崩塌 |
| 攒够大样本再上线统计 | 精度有保证 | 单人合规采集永远到不了"大样本"；MVP 无法演示核心差异化 |

## Decision

**每个统计输出强制附：样本量 N、置信度分级、数据窗口、来源分布（Tier A/B/C 占比）。阈值冻结：**

- N ≥ 200 → High confidence
- 50 ≤ N < 200 → Medium
- 30 ≤ N < 50 → Low（界面明确提示谨慎采信）
- **N < 30 → 不输出统计**（"当前样本量不足以判断趋势"），无例外路径
- 趋势（7/30/90 天）仅在对应窗口样本量达标时计算；snapshot 表 (scope, window) 唯一
- 禁止事项：编造统计、LLM 猜趋势、少量样本代表整个市场、海外数据冒充中国市场

## Consequences

- 正面："每个百分比可点击溯源到 JD 列表"成为可兑现承诺；与市场研究的数据纪律（MARKET_RESEARCH §6.2）完全一致；竞品无此设计——差异化
- 负面：早期多数切片会显示"样本不足"（诚实但影响演示体验）；需要快速积累中国数据集

## Reversibility

撤销成本：**极低**（展示规则），但**原则不可撤**（撤了等于产品说谎）。
复议触发条件：仅阈值数值可随数据规模复议（如数据集破千后提高 High 线）。
